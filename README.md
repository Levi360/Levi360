## 💡 O que já pratiquei

- **POO em Java:** classes, herança, polimorfismo (sobrescrita e sobrecarga) e encapsulamento.
- **API/servidor em Java** conectado ao SQLite via JDBC.
- **Segurança de senhas:** hash com BCrypt (salt incluso) para armazenar e validar credenciais.
- **JSON** tanto em Java quanto em JavaScript.
- **JavaScript:** DOM, `fetch` e `async/await` para consumir a API pelo navegador.
- **Modelagem de banco:** tabelas, chaves primárias e estrangeiras.
- **Linux e terminal:** comandos básicos de navegação e arquivos.
